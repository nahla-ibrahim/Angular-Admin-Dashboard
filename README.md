# 🚀 Admin Dashboard (Angular)

A modern, responsive admin dashboard built using Angular, focused on clean architecture, reusable components, and real-world frontend practices.

---

## 🔗 Live Demo

<a href="https://angular-admin-dashboard-six.vercel.app/">
    <strong> Live Demo 🔗 </strong>
</a>


## ✨ Features

### 🔐 Authentication

* Login system
* Route Guards (Auth & Guest Guards)

### 🧱 Layout

* Responsive Navbar & Sidebar
* Collapsible Sidebar
* Mobile-friendly design
* Dark Mode support

### 📊 Dashboard

* Statistics cards
* Interactive charts (Line, Bar, Pie, and Horizontal Bar)
* Recent activity and notifications
* Clean and modern UI

### 📋 Users & Products Management

* Fetch data from API
* Reusable table with sorting, search, and pagination
* CRUD operations
* Responsive data management interfaces

### 📅 Calendar & Productivity

* Interactive calendar with event creation and deletion
* Persistent events using Local Storage

### ❓ Additional Pages

* Profile page
* FAQ page


---

## 🧩 Reusable Components

* Table Component
* Chart Component
* Modal Component
* Card Component
* Alert Modal Component

## ⚙️ Technologies Used

* Angular 21
* TypeScript
* Tailwind CSS
* Chart.js (ng2-charts)
* RxJS
* REST API (DummyJSON)
